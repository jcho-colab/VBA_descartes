# Overview
In the 'resources files/Macro VBA' folder, you will find the original excel file along with the VBA code I extracted.
It is a complex excel file that contains macros. This is related on FTA tarif rates for which Descartes send us xml files. We maintain our system with the latest information from them.
It has several buttons on the main page to launch the macros, several tabs that are populated by these macros, there is a mapping also with XML files (under developer tab -> source) , many tables that are called during the macros, and more. Based on the xml that are downloaded (see input XML folder), tabs are populated, and several files are generated and saved (see output CSV folder). 
The current code of this project is a translation of what this excel file and its macros do, into a python code.
Most of the code works but there are some issues remaining.

#Process
when a country is chosen and the xml files are loaded, the tabs called DTR and NOM are populated in the excel file (a macro populates them).
For any country, the ZD14 tab will be populated.
If the country is CA, the CAPDR and ZZDE tabs are also populated.
If the country is US, the ZZDF tab is also populated.
If the country is MX, the MX6Digits tab is also populated.

# Validation
Once the tabs called DTR and NOM are populated, the data is processed with the M code from the files 'TableDTR M code.txt' and 'TableNOM M code.txt'. Then, the ZD14 M code is executed, regardless of the country.
If the country is CA, the CAPDR and ZZDE M code files are executed.
If the country is US, the ZZDF M code file is executed.
If the country is MX, the MX6Digits M code file is executed.
